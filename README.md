# Computer Infrastructure

This repository contains my assessment work for the Computer Infrastructure module.
The main work is contained in a single Jupyter notebook, in Python `problems.ipynb`.
Everything needed to run this notebook is included in this repository.

## Quick Look

- You can click [problems.ipynb](./problems.ipynb) in this repository and GitHub will display it in static format.
- You can view and run the notebook in [Google Colab](https://colab.research.google.com/github/Martynas-Ramonas/computer-infrastructure/blob/main/problems.ipynb).
- You can view the notebook using [nbviewer](https://nbviewer.org/github/Martynas-Ramonas/computer-infrastructure/blob/main/problems.ipynb).

## Running the notebook

1. Clone the repository using [Git](https://git-scm.com/).
2. Make sure you have [Python](https://www.python.org/) installed. 
   An easy way to get Python is to use [uv](https://docs.astral.sh/uv/) or [Anaconda](https://www.anaconda.com/download).
3. Install the required packages: 
                                ```bash
                                pip install -r requirements.txt
4. Run the notebook:
                    ```bash
                    jupyter notebook problems.ipynb
